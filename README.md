# 타이야키DB

세계의 붕어빵(타이야키) 가게를 찾고, 방문 기록을 남기는 지도입니다.

**특징:**
- 🗺️ 세계 지도에서 가게를 검색하고 필터링
- 📍 새로운 가게 발견 시 바로 추가 가능
- 📔 방문한 가게와 먹은 것을 기록
- 🏆 지역 제패와 퀘스트로 게임처럼 즐기기

---

## 시작하기

### 🔍 가게 찾기
1. 지도에서 원하는 지역을 선택
2. 나라나 도시로 필터링
3. 가게를 클릭해 상세 정보(전화, 영업시간, 위치 등) 확인

### ➕ 새 가게 추가하기
1. 지도에서 가게 위치를 클릭
2. 가게 이름과 기본 정보 입력
3. "추가" 버튼으로 저장 (내 브라우저에만 임시 저장)
4. **공유하기:**
   - "JSON 복사" → 직접 저장소에 기여
   - "GitHub 이슈로 제안" → 이슈로 건의 (검수 후 반영)

### 📍 위치 정보
- **정확한 위치:** 실제 가게 입구 또는 정문
- **대략적인 위치:** 확실하지 않으면 체크 (주소나 맵 서비스로 재확인 권고)

---

## 📔 방문 기록 · 평가 · 게임

### 방문 기록 남기기
가게 상세 화면의 **"방문 기록 남기기"** 버튼으로:
- 📅 방문한 날짜
- 🍴 먹은 것 (종류 × 피 × 앙)
- 📏 크기 (보통 / 자이언트)
- 💬 메모 추가

### ⭐ 평가하기
같은 팝업에서 먹은 것마다 평가:
- **피의 바삭함:** 1–5점
- **앙의 양:** 1–5점  
- **꼬리까지 앙이 찼는가:** 예/아니오

모든 사용자 평가는 함께 평균되어 가게 상세에 표시됩니다.

### 🏆 퀘스트와 트로피

**지역 제패:**
- 각 도도부현(또는 도시)을 방문하면 지도에 색칠
- 🏙️ 도쿄는 23구 단위로 진행 (23구 완료 시 🏆 트로피)

**수집 퀘스트:**
- 총 방문 횟수
- 같은 가게 방문 횟수
- 다양한 앙 맛 모으기
- 천연/양식 타입 경험하기
- 레어 타이틀 (일본 최북단, 최남단 등 특별한 가게 방문)

**도감:**
- 방문 기록을 모아 60칸짜리 도감 완성 (종류 × 피 × 앙 조합)

기록과 평가는 **브라우저에만 저장되며**, 퀘스트 탭의 "기록 복사/가져오기"로 백업하세요.

## 🌍 가게 정보

### 주요 필드
| 정보 | 설명 |
|------|------|
| **이름** | 가게 이름 (현지어도 함께 표시) |
| **주소** | 지역 · 도시 · 상세 주소 |
| **좌표** | 정확한 위치 |
| **전화** | 예약 및 문의 |
| **영업시간** | 현재 영업 중인지 실시간 판단 |
| **결제 방법** | 현금/카드/교통카드 등 |
| **웹사이트** | SNS 또는 홈페이지 |
| **확인 날짜** | 마지막으로 정보를 확인한 날짜 |

### 가게 종류
- **shop** — 전문점
- **stall** — 포장마차 / 이동 판매
- **chain** — 체인점
- **convenience** — 편의점

### 피와 앙의 종류
**피:** 얇은 피 · 두꺼운 피 · 크루아상 · 하얀 피 · 기타  
**앙:** 큰팥 · 작은팥 · 커스터드 · 초콜릿 · 팥 없음 · 기타

## 🌐 다국어 지원

사이트는 **7개 언어** 지원: 한국어 · 일본어 · 중국어(간체) · 영어 · 독일어 · 스페인어 · 포르투갈어

가게 정보도 여러 언어로 등록 가능합니다.

---

## 💾 내 데이터 관리

### 백업하기
퀘스트 탭 → "기록 복사/가져오기"로:
- 📥 내 방문 기록과 평가를 **JSON으로 복사**
- 📤 다른 기기에서 **JSON 가져오기**

**주의:** 기록은 브라우저 저장소에만 있으므로, 쿠키 삭제나 앱 데이터 초기화 시 사라집니다.

---

## 🔒 개인정보 · 프라이버시

- 📱 **위치 기반 기능** (내 주변 가게)은 HTTPS에서만 작동하며, 위치는 브라우저에만 저장
- 💬 GitHub 이슈 제안 시 공개되는 정보 확인 (방문 날짜, 가게명 등)
- 📊 모든 기록과 평가는 **브라우저에만 저장**되며 서버로 전송되지 않음
